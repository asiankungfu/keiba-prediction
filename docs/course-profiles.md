# コース特徴と「条件適性」の算出ルール

予想の「条件適性」を主観ではなくデータから出すために、各競馬場の特徴を定義し、
対象レースと「似たコース」での過去成績（3着内率）から算出する。

## 1. 基本ルール

```
条件適性 = 100 × 「対象レースと似た条件での3着内率」
```

「似た条件」は次の優先度で過去走を選ぶ:

1. 同じ馬場（芝/ダート）  ← 必須
2. 同じ回り（右回り/左回り）
3. 似た距離（±200m 程度）
4. 同じ競馬場（あれば最優先で加点）

坂の急さ・直線の長さ・コーナーの距離といった物理特徴は、**その競馬場の結果に
すでに織り込まれている**ため、「似たコースでの実績」で間接的に反映される
（坂や直線長から直接確率を出すと根拠の無い数値になるため、そこはやらない）。

## 2. 競馬場プロファイル（JRA 主要）

| 競馬場 | 回り | 芝直線(約) | 坂 | 特徴 |
|------|----|------:|----|----|
| 東京 | 左 | 525m | ゴール前に緩い坂 | 直線が長く差しが届きやすい・紛れ少 |
| 中山 | 右 | 310m | ゴール前に急坂 | 直線短く小回り・先行/器用さ有利 |
| 阪神(外) | 右 | 474m | ゴール前に坂 | 直線長め＋坂でタフ |
| 阪神(内) | 右 | 357m | ゴール前に坂 | 小回り＋坂 |
| 京都(外) | 右 | 404m | 3角に下り坂 | 下りで加速・平坦基調 |
| 中京 | 左 | 412m | ゴール前に急坂 | 左回り＋急坂でタフ |
| 新潟(外) | 左 | 659m | 平坦 | 国内最長直線・究極の差し |
| 札幌/函館 | 右 | 約260-265m | 平坦 | 洋芝・小回り・先行有利 |
| 福島/小倉 | 右 | 約290-293m | 小波 | 小回り・機動力重視 |

> 地方（NAR）の例：船橋・大井・川崎などはダート、基本は右回り（大井は左/右あり）。
> 数値はおおよその目安。正確な最新値は各競馬場の公式情報で確認のこと。

## 3. 似たコースのグループ（例）

- **長い直線・差し向き**：東京 / 新潟外 / 阪神外 / 中京
- **短い直線・小回り・先行向き**：中山 / 福島 / 小倉 / 札幌 / 函館
- **急坂でタフ**：中山 / 阪神 / 中京
- **平坦〜下りで速い脚**：京都 / 新潟

対象レースのコースがどのグループかを見て、同グループ＋同馬場＋似た距離の
過去走を「似た条件」として 3着内率を算出する。

## 4. 適用例

- **安田記念（東京・芝1600・左回り）** → 各馬の「芝・左回り・1400〜1800m（特に東京）」の3着内率。
- **日本ダービー（東京・芝2400・左回り）** → 「芝・左回り・2200〜2400m（特に東京）」の3着内率。
- **有馬記念（中山・芝2500・右回り・急坂）** → 「芝・右回り・2200〜2500m（特に中山）」の3着内率。

## 5. 限界と今後

- 騎手のコース相性、枠順、馬場状態（良/重）、ペース・脚質も本来は効く。
  特徴量として段階的に追加可能（モデル再学習が必要）。
- より厳密には、各馬の全レース履歴をDBに取り込み、対象コースとの類似度で
  重み付けして自動算出するのが理想（JRA-VAN連携で実データ化すれば自動化できる）。
